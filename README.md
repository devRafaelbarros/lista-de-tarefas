# Lista de Tarefas

Aplicação web simples para organizar tarefas do dia a dia, feita com **HTML, CSS e JavaScript puro**.

🔗 **Demo:** https://devrafaelbarros.github.io/lista-de-tarefas/

## Funcionalidades

- Adicionar novas tarefas
- Marcar e desmarcar tarefas como concluídas (clicando nelas)
- Excluir tarefas
- Limpar todas as tarefas concluídas de uma vez
- Contador de tarefas concluídas
- As tarefas ficam salvas no navegador, mesmo depois de fechar a página

## Tecnologias

- HTML5
- CSS3 (Flexbox, variáveis, efeito de vidro e gradientes)
- JavaScript (DOM, eventos, arrays e objetos)
- localStorage para guardar os dados

## O que pratiquei neste projeto

- Manipulação do DOM com `createElement`, `appendChild` e `textContent`
- Eventos de clique e envio de formulário
- Métodos de array: `forEach`, `filter` e `push`
- Conversão de dados com `JSON.stringify` e `JSON.parse`
- Persistência de dados com `localStorage`

## Como rodar localmente

1. Clone o repositório: `git clone https://github.com/devRafaelbarros/lista-de-tarefas.git`
2. Abra a pasta no VS Code
3. Abra o `index.html` com a extensão Live Server
